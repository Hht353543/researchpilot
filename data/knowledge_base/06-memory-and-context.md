# Agent 记忆分层与上下文管理

## 三层记忆

短期记忆（Short-Term）保存当前任务的对话与临时观察，必须有 token 上限与滚动淘汰策略。

工作记忆（Working）保存当前研究任务的结构化状态：计划、子任务、证据、中间结果。它是编排器的主要读写对象，也是任务可恢复性的基础。

长期记忆（Long-Term）跨任务保存用户偏好、研究主题、历史结论与重要事实，需要有去重、TTL、重要度与来源字段。

## 去重与重要度

长期记忆写入前应做相似度去重（例如 Jaccard 或向量相似度阈值），命中重复时累加命中次数并按需提升重要度。检索时按重要度、时间衰减与相关度加权排序，避免旧结论压过新事实。

## TTL 与遗忘

偏好类记忆可长期保留，事实类记忆应设置有效期（例如 90~180 天），过期后自动淘汰或降权。缺少 TTL 的记忆库会逐渐退化为噪声来源。

## 上下文溢出

常见策略：按重要度排序后截断、对历史证据做摘要压缩、把原始证据留在磁盘只在上下文中放摘要与 id。工程上应显式记录被截断的内容，避免"看起来有依据但实际未被模型看到"的隐性错误。
