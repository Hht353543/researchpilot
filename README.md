# ResearchPilot

个人资料研究助手：选定自己的文档与笔记，生成可核对、可继续追问的中文报告。

## Windows 使用

1. 拿到 `ResearchPilot.exe` 后，放在任意方便的位置，双击打开。
2. 浏览器会自动打开。首次使用粘贴自己的 **DeepSeek API Key**，点击“测试并保存”。
3. 在“我的资料”导入文件，回到研究页勾选本次使用的资料，再输入问题并开始研究。
4. 完成后点击引用、展开原文核对；可继续追问，或下载 HTML / Markdown、打印保存 PDF。

不需要安装 Python、Git、Docker，不需要打开终端、编辑配置文件或安装依赖。支持 Windows 10 / 11 x64。

支持文字版 PDF、DOCX（正文与表格）、TXT、Markdown、CSV、JSON、JSONL，也可以直接粘贴文本。中文文本支持 UTF-8 和 GB18030；扫描件需先做 OCR。研究仅使用本次勾选的资料，**不包含实时联网搜索**。新安装从空资料库开始，首页“载入示例资料体验”单独使用示例；示例不会默认混入个人研究。

在“设置”中可以替换、清除 API Key 或选择 OpenAI、其他兼容服务。页面提供密钥获取和当前计费链接。API Key 使用 Windows 当前用户加密保护，页面只显示是否已设置。连接测试及研究会使用你自己的模型账户用量，所选资料片段会发送到已连接的模型服务。

引用存在只是第一步：程序检查原文出处、结论含义，并在报告生成后再核对正文。未能充分支持的生成文字会退回原文摘录；建议标为推断，缺少依据的部分明确提示。模型审查仍可能出错，请沿引用核对关键结论。

关闭浏览器后，研究仍会继续。再次双击程序会打开已有实例。要退出程序，在系统托盘菜单选择“退出”，或在“设置 → 诊断与程序管理”中退出；运行中的研究会先提示取消。

配置、导入资料和历史自动保存在当前 Windows 用户的数据目录。移动或替换 EXE 后仍能继续使用。
