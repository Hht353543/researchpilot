# ResearchPilot

输入一个问题，基于内置或自己导入的资料生成研究报告，沿着引用查看依据。

## Windows 使用

1. 拿到 `ResearchPilot.exe` 后，放在任意方便的位置，双击打开。
2. 浏览器会自动打开。首次使用粘贴自己的 **DeepSeek API Key**，点击“测试并保存”。
3. 输入研究问题，点击“开始研究”。完成后阅读报告、查看引用，也可以复制或下载报告。

不需要安装 Python、Git、Docker，不需要打开终端、编辑配置文件或安装依赖。支持 Windows 10 / 11 x64。

在“团队知识库”中选择文件即可导入 TXT、Markdown、CSV、JSON、JSONL，也可以直接粘贴文本。中文文件支持 UTF-8 和 GB18030。研究使用内置或导入的资料，**不包含实时联网搜索**；内置网页样本会明确标识。

在“设置”中可以替换、清除 API Key 或选择 OpenAI、其他兼容服务。高级参数默认折叠。API Key 使用 Windows 当前用户加密保护，页面只显示是否已设置。连接测试及研究会使用你自己的模型账户用量。

关闭浏览器后，研究仍会继续。再次双击程序会打开已有实例。要退出程序，在系统托盘菜单选择“退出”，或在“设置 → 诊断与程序管理”中退出；运行中的研究会先提示取消。

配置、导入资料和历史自动保存在当前 Windows 用户的数据目录。移动或替换 EXE 后仍能继续使用。
