# 个人资料研究最终验收表

当前目标：证明交付的 Windows 成品能让未参与开发的人用自己的资料完成研究，并用当前真实模型核验答案与成本。工程回归、合成资料实验和独立用户验收分别记录。

## 真实模型评审

固定用例见 [合成验收资料](../eval/personal_acceptance.json)。执行器复用现有 Provider、知识库和 ResearchPipeline，将每题的原始结果、Markdown、实际 API usage 保存到独立输出目录。账户余额变化仅留在本地，不纳入公开数据。它不产生人工评分。

```powershell
python scripts/personal_acceptance.py --desktop-data-dir output/personal-acceptance-app --output-dir output/personal-live/review-new --followup
python scripts/personal_acceptance.py --desktop-data-dir output/personal-acceptance-app --code-root output/goal-baseline --output-dir output/personal-live/review-old
```

执行前在对应桌面数据目录的连接页测试并保存 Key；不在命令行或文档填写密钥。旧版源码须来自交付记录指定的基线提交。输出目录必须是新目录。`--max-total-tokens` 在题目之间检查；每题另有 30,000 token 预算，触发预算的最后一次响应仍会计费，不能视为严格的费用上限。

已有实验为 2026-10-05 的 DeepSeek 官方 `deepseek-flash`（DeepSeek-V4.1-Flash），详见 [交付记录](personal_research_delivery.md) 和 [真实模型数据](personal_live_comparison.json)。最终成品 SHA-256：`b24ff926587ec977126314cd5d2b67d2647d8aae9580456a6b7f73212d910453`。固定参数结果位于 `output/personal-live/final/<用例>/initial.json`／`.md`；否定追问为 `negation/followup.json`／`.md`。EXE 默认参数日期题和追问另存 `output/personal-live/exe-initial.json`、`exe-followup.json` 及同名 Markdown。

以下观察仅用于安排评审：固定参数日期题触发预算回退并漏答上线日期，否定追问有一条未知来源 `metadata` 的生成证据被丢弃；默认参数 EXE 初始题恢复三项事实，追问正文有日期但摘要遗漏，收入变化部分退回原始数字。各题均为 degraded，重复摘录、重复引用及无依据的限制推断仍需核对。

## 旧新版对照

比较六个初始问题；新版额外的追问单列。固定同一模型、资料、问题、hash embedding、top_k=4、temperature=0.1、max_iterations=1、max_tokens=1200 和每题 token 预算。两版都只允许知识检索、原文读取与元数据工具。旧版没有选定范围和父任务字段，因此每题使用独立的知识库；此实验验证固定资料下的生成链路，不能代替旧版桌面范围隔离验收。

| 指标 | 旧版 | 新版 |
| --- | --- | --- |
| 人工完全通过题目／6 | 待评审 | 待评审 |
| 漏答／误答／误报 | 待评审 | 待评审 |
| 六题实际 HTTP 成功响应数 | 67 | 49 |
| 六题实际 tokens | 99,030 | 112,865 |
| 单题平均耗时（单次观测） | 36.149 秒 | 26.153 秒 |

这是各版本一次顺序执行实验；缓存、上游负载与采样会影响价格和耗时。调用减少但 tokens 增加，不能据此声称全面节省成本。余额差额可能包含同账户并行活动，须由账户用量明细最终核对。项目价格表只提供峰时、缓存未命中的保守估算；不能用旧版价格表中的 0 美元替代实际费用。账单核对人、用量明细和同题成本结论均待填写。
