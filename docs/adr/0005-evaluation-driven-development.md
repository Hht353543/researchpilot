# ADR-0005: 以 Golden Dataset + 代码判分驱动开发

- 状态：已采纳
- 日期：2026-09-13

## 背景

LLM 应用容易出现"看起来能跑"但无法量化的假象；使用 LLM 当裁判又会引入不可复现性。

## 决策

1. 建立 35 条 Golden Dataset，覆盖 12 类场景（含故障注入、注入攻击、无结果等负向场景）；
2. 判分完全由代码完成（报告存在性、关键词/禁用词、引用可解析率、召回率、工具集合、
   缺口声明、故障处理、延迟预算、状态）；
3. 指标从真实运行与 Trace 计算，禁止手工填写；
4. `docs/evaluation.md` 与 `docs/resume.md` 均由脚本生成，禁止手工美化数字；
5. CI 中运行离线评测作为回归门槛（`tests/evaluation/test_smoke.py`）。

## 结果

优点：可复现、可回归、可对比；RL 领域的"评测先行"思路被落到工程流水线中。
新增 Agent 能力时，先扩展数据集与判分，再实现功能。

代价：数据集与判分需要持续维护；代码判分对语义类问题的覆盖有限（因此保留 LLM 判分的扩展位，
但默认不启用，避免不可复现）。
