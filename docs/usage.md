# 使用 ResearchPilot

双击 `ResearchPilot.exe`，等待浏览器自动打开。第一次粘贴自己的 DeepSeek API Key，点击“测试并保存”。无需安装其他环境。

## 第一次研究

首页输入你想了解的问题，或者选一个示例，点击“开始研究”。默认参数已经准备好，不必打开高级选项。

研究过程中可以切换页面或关闭浏览器。再次双击程序即可回来查看。完成后，正文引用会定位到对应来源；有引用的来源卡片可展开查看引用原文。报告可以复制或下载为 Markdown。

研究基于程序附带和你导入的资料，不包含实时联网搜索。内置网页样本只是内置资料，会标明未联网核验。

## 加入自己的资料

进入“团队知识库”，点击“导入文件”，选择 TXT、Markdown、CSV、JSON 或 JSONL 文件。程序自动读取并加入研究资料。中文文件可使用 UTF-8 或 GB18030。文件过大或格式不正确时，页面会提示原因。

也可以点击“添加资料”，直接粘贴文本。CSV 默认使用 `title`、`content`、`source` 列；JSON 可使用一个对象或对象列表，每个对象包含 `content`；JSONL 每行一个这样的对象。无需改程序设置。

知识库中的资料可删除。高级“知识库维护”入口可以重建索引，重建会保留导入资料，也不会恢复已删除的资料。

## 连接与偏好

在“设置”中可以替换或清除 API Key。默认使用 DeepSeek，展开连接选项可以切换 OpenAI 或其他兼容服务。连接失败时按页面提示检查密钥、余额、网络或模型。

研究偏好及高级参数修改后，点击“测试并保存”即可应用到后续研究，重启仍有效。正在研究时，需等任务结束或取消后再修改连接。

密钥只加密保存在当前 Windows 用户的电脑中。换一个 Windows 用户或换电脑后需要重新输入。连接测试和研究都会消耗模型账户用量。

## 退出与诊断

关闭浏览器不会退出程序。可在右下角系统托盘中选择“退出”，也可从“设置 → 诊断与程序管理”退出。若有任务运行，会提示是否取消后退出。

启动失败会显示中文窗口，可点击“重试”或查看诊断文件夹。设置中也可以查看、下载已脱敏的诊断信息。

配置、知识库、历史和日志均自动保存。移动 EXE 或用新版本替换 EXE 不会删除这些资料。
