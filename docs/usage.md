# 使用 ResearchPilot

双击 `ResearchPilot.exe`，等待浏览器自动打开。第一次粘贴自己的 DeepSeek API Key，点击“测试并保存”。无需安装其他环境。

## 第一次研究

先在“我的资料”导入文档。回到首页，在问题下方勾选本次要研究的资料，输入问题后点击“开始研究”。资料不会自动全部混入每次研究。

研究过程中会显示实际阶段：规划、检索、核对、补检、写作和报告复核。可以切换页面或关闭浏览器，稍后回来查看。完成后，点击正文引用可定位到对应来源，展开查看原文。

点击“追问”后输入新的问题，会继承上一份报告、证据和资料范围，并重新检索核对事实。需要更换资料时点击“新建研究”。被删除的资料不能继续用于追问，需重新选择资料研究。

报告可以复制或下载 Markdown，也可下载可直接打开的 HTML；“打印 / 保存 PDF”使用浏览器打印对话框。报告区分有依据的结论、推断建议和证据不足；模型核对不保证正确，重要信息请核对原文。

研究仅使用选定的资料，不包含实时联网搜索。“载入示例资料体验”会进入独立示例范围，返回个人资料研究后不包含示例。示例研究也会消耗模型账户用量。

## 加入自己的资料

进入“我的资料”，点击“导入文件”，选择文字版 PDF、DOCX、TXT、Markdown、CSV、JSON 或 JSONL 文件。PDF 保留页码标记，DOCX 提取正文与表格；扫描 PDF 没有可提取文字时会提示先做 OCR。中文文本可使用 UTF-8 或 GB18030。文件过大或格式不正确时，页面会提示原因。

桌面单次导入请求上限为 8 MiB；PDF/DOCX 使用编码传输，原始文件需小于约 6 MiB。提取后的正文上限为 50 万字符，较大资料请拆分。

也可以点击“添加资料”，直接粘贴文本。CSV 默认使用 `title`、`content`、`source` 列；JSON 可使用一个对象或对象列表，每个对象包含 `content`；JSONL 每行一个这样的对象。无需改程序设置。

知识库中的资料可删除。高级“知识库维护”入口可以重建索引，重建会保留导入资料，也不会恢复已删除的资料。

## 连接与偏好

在“设置”中可以替换或清除 API Key。默认使用 DeepSeek，展开连接选项可以切换 OpenAI 或其他兼容服务。连接失败时按页面提示检查密钥、余额、网络或模型。

普通使用采用保存的默认研究参数。其他兼容服务需要填写地址和模型名称。正在研究时，需等任务结束或取消后再修改连接。

密钥只加密保存在当前 Windows 用户的电脑中。换一个 Windows 用户或换电脑后需要重新输入。密钥在服务商控制台创建，设置页提供获取及计费链接；连接测试和研究都会消耗账户用量，所选资料片段会发送到已连接的模型服务。

## 退出与诊断

关闭浏览器不会退出程序。可在右下角系统托盘中选择“退出”，也可从“设置 → 诊断与程序管理”退出。若有任务运行，会提示是否取消后退出。

启动失败会显示中文窗口，可点击“重试”或查看诊断文件夹。设置中也可以查看、下载已脱敏的诊断信息。

配置、知识库、历史和日志均自动保存。移动 EXE 或用新版本替换 EXE 不会删除这些资料。
